# Cult Tycoon (working title)

A cozy-looking, pitch-black-funny pixel-art management sim: build a compound, recruit gullible followers, and court
ancient entities who are terrible bosses. Tycoon spine + match-3 rituals + merge Reliquary + alchemy.

Personal project, no monetization. Web-first PWA (Phaser 3 + TypeScript + Vite).

Start with `CLAUDE.md`, then `docs/GDD.md` and `docs/TASKS.md`.
