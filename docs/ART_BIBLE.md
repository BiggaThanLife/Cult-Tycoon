# Art Bible

Owner: pixel-artist · All art is original programmer art (D-004). Feel: Kairosoft-like chunky SD sprites. Never trace or copy any existing game.

## 1. Resolution & scaling
- Logical canvas: portrait min **180×320**, landscape min **320×180**. Integer scale `s = floor(min(w/minW, h/minH))` (device px), then the
  logical size grows to `floor(w/s) × floor(h/s)` so extra screen shows **more world**, never stretched pixels.
- `pixelArt: true`, `roundPixels: true`, no texture filtering. Never render at fractional scale.
- Reference devices: 390×844 @3× → scale 6, logical 195×422; 412×915 @2.625 → scale 6, logical 180×400; 1280×720 desktop → scale 4, logical 320×180.
  At scale 6 a 20px ritual tile is ≈ 40–44 CSS px; a 5×8 glyph is ≈ 14–16 CSS px tall.
- Safe areas: read `env(safe-area-inset-*)`, convert to logical px, and keep HUD anchors inside.

## 3. Palette (32 colors, "Candy Pastel + Night Glow")
Day pastels, deep night purples, plus a small set of "wrong" accents. Store as `assets/palette.json`; all generated sprites
must quantize to it.
```
Outline/ink   #1b1428 #3a2a4d
Skin          #f2c9a0 #d99a6c #a8673f #6b3f2a
Robes         #e8dff5 #b8a5d9 #7b62a8 #4b3a73
Grass/plants  #b6e3a1 #7cc47a #4a8f5a #2f5e45
Earth/wood    #f0d9a8 #d1a46e #9a6b45 #5e4030
Candy accents #ff9fb6 #ffd36e #8fd3ff #c39bff
Night glow    #2a1f4a #3d3470 #58e0c6 #b6ff7a
Wrong details #c2304f #7a1630 #e8e2c8 #ffffff
```
- Night: overlay tint `#2a1f4a` @ 45% + additive glow sprites (eyes, candles, runes) in teal/acid green.
- Stains, glowing eyes and hood shadows are the "wrong" details. Keep them small (1–3 px).

## 6. UI rules
- Panels: 1px ink outline, 1px inner highlight, 9-slice 8×8 corners, robe-light fill `#e8dff5`.
- Touch targets ≥ 44 CSS px (check per device scale); primary actions in the bottom 40% in portrait.
- Numbers always visible on stat bars ("Devotion 42/100").
- Floating text colors: gains `#7cc47a`, losses `#c2304f`, ironic/quoted `#c39bff` ("Follower is \"fine\"").
- Speed toggle (1×/2×/4×) top-right of the resource bar.
- Landscape: side docks are 96–120 logical px wide; the board/camera never scales up.

## 7. Pipeline
- Sprites are generated by scripts in `tools/art/` (TypeScript → PNG via node-canvas or pngjs) from small pixel maps/strings, then packed into atlases.
- `assets/manifest.json` lists every asset: key, file, size, frames, source script, `needsHumanPass: true|false`.
- Human-pass candidates (flagged now): patron entity portraits, the title screen, the four ending illustrations.
